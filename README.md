# منصة شواهد لتقويم الأداء المدرسي 🏫

منصة رقمية متكاملة لتوثيق وأرشفة شواهد ومعايير التقويم المدرسي (الذاتي والخارجي) للمدارس في المملكة العربية السعودية، وفق معايير **هيئة تقويم التعليم والتدريب (ETEC)** بالتعاون مع **وزارة التعليم** (الإصدار الثاني 2026م).

---

## 🌟 أبرز مميزات المنصة

- **المجالات الأربعة المعتمدة**: تغطية كاملة للمجالات (الإدارة المدرسية، التعليم والتعلم، نواتج التعلم، البيئة المدرسية) بكافة معاييرها ومؤشراتها.
- **بوابة عامة للزوار ولجان التقويم**: تصفح المؤشرات ونسب الإنجاز والشواهد المعتمدة مباشرة دون تسجيل دخول مع محرك بحث فوري.
- **بوابة المعلمين والكوادر التعليمية**:
  - رفع الشواهد السحابية (روابط، مجلدات Google Drive / OneDrive، فيديوهات، عروض تقديمية).
  - **منشئ تقارير التوثيق A4**: بناء تقارير إلكترونية مهيكلة مع ضغط الصور ومعاينتها فورياً.
  - **دعم 8 قوالب تقارير متخصصة**: (برامج وأنشطة، استراتيجيات تدريس، مبادرات مدرسية، ورش عمل، اجتماعات، مناسبات وطنية، زيارات صفية، تحليل نتائج).
  - **مساعد الذكاء الاصطناعي التربوي**: توليد تلقائي للأهداف والخطوات والمخرجات المتوافقة مع الصياغة التربوية السعودية الرسمية.
- **لوحة تحكم المدير والإدارة**:
  - تدقيق الشواهد واعتمادها أو رفضها مع كتابة الملاحظات.
  - إدارة المعلمين والمستخدمين والصلاحيات.
  - تخصيص بيانات المدرسة (الاسم، الإدارة التعليمية، الشعار، الختم الرسمي، العام الدراسي).
  - سجل رقابي زمني للعمليات الإدارية (Audit Log).
- **محرك طباعة وتصدير PDF متقدم**:
  - تصدير تقارير A4 بدقة متناهية متوافقة مع الطباعة الرسمية.
  - دعم التواريخ الهجرية حصراً وبالأرقام العربية المشرقية.
  - إدراج التوقيعات الرسمية وختم المدرسة تلقائياً.

## 🛠️ المكدس التقني (Tech Stack)

- **Framework**: Next.js 14 (App Router) & React 18
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS (واجهة عربية بالكامل RTL مع ألوان هوية وزارة التعليم)
- **Database**: PostgreSQL (عبر Supabase) مع Prisma ORM
- **Storage**: Supabase Storage + Local Backup
- **PDF Engine**: Playwright & @sparticuz/chromium
- **Image Processing**: Sharp (ضغط WebP وتعديل القياسات)
- **Auth**: JWT Sessions عبر Jose و Bcryptjs (HTTP-Only Cookies)

## 🚀 متطلبات التشغيل والبدء السريع

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية:
أنشئ ملف `.env` واملأ بيانات الاتصال بقاعدة بيانات Supabase:
```env
DATABASE_URL="postgresql://postgres.[REF]:[PASS]@aws-0-eu-central-1.pooler.supabase.com:6543/postgres?pgbouncer=true"
DIRECT_URL="postgresql://postgres.[REF]:[PASS]@aws-0-eu-central-1.pooler.supabase.com:5432/postgres"
NEXT_PUBLIC_SUPABASE_URL="https://[REF].supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your-anon-key"
SUPABASE_SERVICE_ROLE_KEY="your-service-role-key"
JWT_SECRET="your-secure-jwt-secret"
```

### 3. تهيئة قاعدة البيانات وزراعة البيانات الأولية:
```bash
# توليد كود Prisma Client
npx prisma generate

# مزامنة الجداول
npm run db:push

# إدخال بيانات المجالات والمعايير والمؤشرات والمستخدمين الافتراضيين
npm run db:seed
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`
